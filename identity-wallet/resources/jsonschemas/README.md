This folder contains the Json schemas of 3 digital credential data format:

1. Verifiable Credential Data Model 1.1 [https://www.w3.org/TR/vc-data-model-1.1]
2. Verifiable Credential Data Model 2.0 [https://www.w3.org/TR/vc-data-model/]
3. OpenBadges Specification 3.0 [https://www.imsglobal.org/spec/ob/v3p0]

The Json schema files are named accordingly, their sources are:

1. Created by us, Impierce, based on the specification (https://www.w3.org/TR/vc-data-model-1.1)
2. https://github.com/w3c/vc-data-model/blob/main/schema/verifiable-credential/verifiable-credential-schema.json
3. https://www.imsglobal.org/spec/ob/v3p0#achievementcredential-0

# UniMe app reference

Every screen of the UniMe app: what it is for, its controls with their English labels, the screens it opens and the actions it sends to the backend.

This file is generated by `scripts/generate-app-reference.mjs` from the routes in `unime/src/routes`, the Svelte components of each screen and the English translations in `unime/src/i18n/en/index.ts`. Do not edit it by hand. Change the code, or the names and purposes in `scripts/app-reference-screens.json`, and run `pnpm docs:app-reference`.

## How to read an entry

- The line under the name gives the route of the screen and the file that implements it. A part in square brackets, as in `/credentials/[id]`, is a parameter.
- **Title bar** is the title in the bar at the top of the screen.
- **Controls** are the buttons, links, fields and switches, with the screen each one opens and the backend action it dispatches where the code states that directly. A control whose handler is a function shows no effect here. The lines **Opens** and **Backend actions** list everything the screen can open or dispatch.
- In a label, `{name}` marks a value that the app fills in, and `one/other` marks a singular and a plural form.
- **Opened from** lists the screens with a control or a redirect that leads here. Screens that the backend opens, such as the prompts, say so in their purpose.
- Backend actions are handled by the reducers in `identity-wallet/src/state`.
- Controls that only show in developer mode, or once the developer mode setting is unlocked, are marked.
- An entry lists every control that the components of a screen can show. Which of them show at a given moment depends on the state of the wallet.

## Layouts

A layout wraps the screens in its folder below `unime/src/routes`, and the layout `/` wraps every screen of the app. What a layout shows and does applies to all of its screens, so it is listed here once. A screen whose file name has an `@` skips layouts: `+page@.svelte` keeps only the layout `/`, and `+page@name.svelte` keeps the layouts down to the folder `name`.
